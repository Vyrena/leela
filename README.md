# Leela

Leela is a witty, voice-enabled desktop AI assistant designed for Windows.

## Planned v1

- system tray app with floating chat panel
- voice-ready chat experience
- persistent local settings and memory hooks
- OpenRouter-powered assistant backend

## Stack

- Electron
- React + TypeScript
- Zustand
- Electron Store

## Development

```bash
npm install
npm run dev
```

Node.js is required locally to install dependencies and run the desktop app.
